# Java Practice: Data Structures & Algorithms

I'm Dominic, a Computer Science student at Brooklyn College (CUNY), graduating May 2028. This repo holds my Java solutions to common interview-style problems. Each problem is solved more than one way, so I can compare the approaches and their trade-offs.

## Problems

| Problem | File | Approaches | Time |
|---|---|---|---|
| Two Sum | `TwoSum.java` | Nested loops; HashMap | O(n²); O(n) |
| Contains Duplicate | `ContainsDuplicate.java` | Nested loops; HashSet | O(n²); O(n) |
| Valid Anagram | `ValidAnagram.java` | Sort and compare; letter counts | O(n log n); O(n) |
| Valid Parentheses | `ValidParentheses.java` | Stack (push the expected closer) | O(n) |
| Best Time to Buy and Sell Stock | `BestTimeToBuyAndSellStock.java` | Nested loops; one pass tracking the lowest price | O(n²); O(n) |
